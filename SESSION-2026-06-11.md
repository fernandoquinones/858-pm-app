# Session log — June 11, 2026

## Headline
Zoomed out from "event project tool" to **858 Hub — a company operating system**. Event project plans become one **module** (tile) among several. Triggered by thinking about integrating Granola.

## What we decided
- **Vision:** a hub with a tiled landing page; events = Module 1. Modules: Project plans (live), Company brain (Granola), Client portal & dossiers, CRM, Reports, Docs.
- **Four layers:** spine (Supabase: events/projects/tasks) · connectors (systems of record) · brain (Claude) · modules (the rooms). The "hub" is only 3 thin shared things: home/nav, logins, the spine.
- **Source of truth (locked):** Attio = CRM (operators, accounts, target connections, deals) · Supabase = events/projects/tasks · Granola = meetings/brainstorming · Drive = docs/contracts · Slack = comms.
- **Ambient query bar:** a Claude query bar on the hub home (asks across everything you can see) AND on each module page (scoped to that module). The project plan page already proves the pattern (Reports & Views + Add-with-Claude).
- **Granola = input to the brain**, not "into the project plan." The brain then serves whichever module needs it.

## Permissions & governance (the big thread)
- **Principle:** the hub never widens access beyond what a meeting/record intended (Marty+JG closed talk never leaks).
- **Scoped brain:** one brain, answers filtered per-user; filter AT RETRIEVAL before the model sees data — never "ask Claude not to mention." Depends on Layer 3.
- **Three control layers:** (1) Granola source — private by default, API key scopes, dedicated "858 Projects" folder or per-user auth; (2) ingestion — opt-in routing (the prompt) beats auto-pull, safe with no security because a human is the gate; (3) hub — logins + Supabase RLS; items inherit project/attendee membership.
- **Consequence now:** until logins (Layer 3) exist, the prototype is internally "everyone sees everything," so only route shareable/project meetings in the pilot; keep sensitive 1:1s out.
- **Sequence:** (1) prompt-to-add-notes pilot now (non-sensitive only) → (2) logins + RLS (unlocks scoped brain + auto ingestion + client data) → (3) Granola folder/per-user scoping + automatic ingestion.
